## Этап 2. Таймлайн

- [ ] Полоса обзора: тонкая линия внутри таймлайна, только акцентный ползунок вида (без подложки всей области); при наведении
  чуть больше и показывает общую волну; тянется за место захвата.
- [ ] Посередине звукового клипа — тонкая тёмная линия громкости, при наведении ярко-белая; тянется, Ctrl+клик — ключ.
  У видеоклипа так же — прозрачность.
- [ ] Ctrl во время перетаскивания любого параметра (ползунки, линии, ключи, кривые) — точнее и медленнее.
- [ ] Фейды: наклонная чёрточка слегка закруглена к углу; при наведении только подсвечивается, не растёт.
- [ ] Буква A (и V) посередине высоты дорожки.
- [ ] Клавиши (и по возможности остальные из Premiere, `@SATURNi.kys`): W — разрезать (ничего не выделено — всё под ползунком, выделено — выделенное);
  A / D — ровно на кадр назад / вперёд (видео и звук); Z / C — к прошлому / следующему ключу выбранного эффекта; Shift+Z — Ease Out,
  Shift+C — Ease In (Saturni сказал «по C Easy In», но C уже переход к ключу — уточнить), Shift+X — плавность между всеми ключами;
  Ctrl+A — все элементы, Ctrl+Shift+A — все ключи выделенного клипа.
- [ ] Рамка выделения из промежутков между дорожками: клипы или (внутри клипа) только ключи. Правый клик по ключам — режимы
  (линейный, плавный, удержание, Bezier); плавность без ограничений по длине, как в After Effects.
- [ ] Кнопка «волны» у инструментов: показывать на клипах линии эффектов — нет / только выбранный / все изменённые разными цветами
  (правый клик — галочки, какие эффекты не показывать, запоминается). Заголовок любого эффекта переключает его линию на таймлайн;
  правый клик по линии — выбрать, какой эффект она меняет.
- [ ] Правый клик по таймлайну: Add media (звук на звуковой дорожке, видео / картинка / графика на видео), Add adjustment layer.
- [ ] Adjustment layer (видео сверху, звук снизу): эффекты, движение, заливка цветом внутри него; правый клик — к каким дорожкам относится
  (не выбрано — ко всем под ним / над ним); в имени — умное название по эффектам и «V1–V3» / «A1–A2», куда действует.
- [ ] Freeze frame (правый клик по видео): кадр на дорожку выше (свободную или новую), 1 с, остальное не двигать.
- [ ] Скорость (правый клик): во сколько раз / какая длина, сдвигать ли остальное, сохранять тон звука, Reverse; плавное замедление —
  интерполяция кадров нейросетью (RIFE — на ней работает Flowframes; проверить, это ли «на F»), ключи скорости с хорошим откликом.
- [ ] Превью никогда не мигает чёрным при смене слоёв, звука, эффектов (проверить все случаи).

## Этап 3. Панель эффектов (вариант A)

- [ ] Вид: ряд = ползунок; заголовок группы в одну строку: название, стрелка, синяя точка «изменено»; клик по названию сворачивает;
  по умолчанию всё раскрыто; кнопки «свернуть / развернуть все» и (правый клик) «только неиспользуемые».
- [ ] Шапка: Effects, график (вкл/выкл, правый клик — гистограмма / Waveform / Vectorscope, два рядом, выбор), сравнение до/после по зажатию
  (правый клик — по зажатию или по клику), Reset, пресеты.
- [ ] Порядок по частоте использования: Motion (позиция, размер, поворот, прозрачность) → Light (Exposure, Contrast, Highlights, Shadows, Whites, Blacks)
  → Color → HSL (пипетка: выбрать / добавить / убрать цвет; показ выделенной области) → Curves (переключатель режимов вместо листания:
  RGB / Red / Green / Blue, Hue vs Saturation, Hue vs Hue, Hue vs Luma, Luma vs Saturation, Saturation vs Saturation — как в Premiere)
  → Detail (Sharpness, Clarity = выделение границ, Smoothing = шумодав, Grain) → Vignette (в обе стороны: тёмная / светлая, Amount, Midpoint,
  Roundness, Feather) → Glow (как Wonder Glow: Intensity, Threshold, Radius, Color, Saturation) → Blur (области, инверсия, «хлопья» / рваный)
  → Pixelate (размер, Posterize, JPEG-ухудшение) → Glitch → Flicker (сила, частота, случайность, через прозрачность) → Shake (X, Y, частота)
  → Lens (рыбий глаз ↔ подушка) → Distortion (как в галерее Poco: точка, сила, цвета).
  Лёгкие эффекты — через шейдер и прозрачность, тяжёлые грузятся только при включении.
- [ ] Маска у любого эффекта (правый клик → Add mask): форма, закругление, размер, растушёвка, инверсия.
- [ ] Пресеты: сохранить, применить; режим «всё» или «только изменённое» (тогда пресеты складываются). Правый клик по эффекту —
  «сделать это значением по умолчанию» (ноль сдвигается на новое место).
- [ ] Всё то же в экспорте (ffmpeg) и в превью одинаково; проверить совпадение.

## Этап 4. Звук

- [ ] Компрессор с графиком, лимитер, Gain.

  хорошо видно, как компрессия меняет тихое и громкое.
- [ ] Audio Cleaner (`#Audio Cleaner`) внутри: правый клик по звуковым клипам → окно очистки для выделенных; настройка сохраняется у клипа,

- [ ] Измеритель: сегменты (вкл/выкл, ширина в настройках), тоньше, крошечные цифры, верхняя и нижняя граница видны всегда;
