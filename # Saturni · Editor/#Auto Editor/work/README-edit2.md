# «#2 Человек-авторитет» — как собран (этап 2)

Пайплайн целиком в коде, чтобы любой шаг можно было переделать:

| Шаг | Файл | Что делает |
|---|---|---|
| Реплики | `transcribe_windows.py` → `transcripts.json` | faster-whisper (large-v3-turbo, GPU) по окнам всех клипов из `highlights` + окну интро; слова с таймингами. Пустые клипы дают «Субтитры сделал…» — это галлюцинация Whisper на тишине, такие клипы считаем безмолвными. |
| Музыка | `onsets.py` → `onsets.json` | Sleep Token — Jaws. Дроп на 69.41 с трека, полу-доля 0.443 с (~135 BPM), тяжёлый блок → провал 76.5–77.9 → второй блок. Онсеты (спектральный flux) — для «прилипания» склеек. |
| Монтаж | `build_edl.py` → `edl.json` | Список склеек: интро 1:1 из `edit2`, дальше склейки по сетке полу-долей с «прилипанием» к онсетам (режем на кадр раньше удара). Клипы вырезаются ffmpeg кадр-в-кадр в `public/clips/`. Лицо героя (YuNet) → центр «punch»-зума; в групповых кадрах поправлено руками. |
| Звук | `build_audio.py` → `public/audio/mix.wav` | Диалоги (+6 дБ) + музыка с приглушением по карте речи (слова интро → маска → атака 60 мс / релиз 300 мс) + SFX (синтезированный райзер, bass drop, cinematic hit, затвор камеры, каменный удар). Отчёт по уровням печатается в консоль. |
| Картинка | `src/Edit.tsx` | Remotion: дуга цвета (холодное интро → полный цвет на дропе), punch от лица, RGB-сплит/тряска/вспышка на ударах, заморозка «селфи» со вспышкой, замедленный финал (ffmpeg minterpolate), зерно, виньетка, титры. |

Перерендер: `npx remotion render Edit out.mp4 --codec=h264 --crf=16 --audio-codec=aac --audio-bitrate=320k`
Смена слова в титре: `TitleSlam text="…"` в `Edit.tsx`.
