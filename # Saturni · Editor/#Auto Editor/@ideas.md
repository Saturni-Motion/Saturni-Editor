# #Auto Editor: идеи на будущее

Источник: `@creating.txt` (переписка с Gemini про черновой монтаж по командам с площадки).

## Что здесь сейчас

Проект Remotion 4.0.528 (React), собранный под ролик «#2 Человек-авторитет»: `work\` — пайплайн на Python
(реплики faster-whisper, удары музыки, склейки по сетке, звук), `src\Edit.tsx` — картинка, `work\README-edit2.md` — как собрано.
Всё установлено: пакеты, браузер для рендера (`node_modules\.remotion\chrome-headless-shell`), навыки Remotion для Claude (`.claude\skills`).
`_test\` — пробные рендеры и кадры прошлой сессии, 130 МБ.

## Идея из @creating.txt

Черновой монтаж без рук: оператор говорит на площадке команды («дубль 2», «брак», «оставь оба»), ИИ слушает весь материал,
понимает команды и выдаёт проект Premiere только с чистыми дублями, без пауз и трёпа между ними. Дальше человек ставит планы, цвет, графику.

## Предложения

1. **Словарь площадки** — файл `@commands.md`: какие слова что значат («дубль», «брак», «ещё раз», «оставь оба», хлопок).
   Claude читает его вместе с расшифровкой и размечает дубли: начало, конец, годен или нет, почему.
2. **Дубли одной мысли**: склеивать в группы по смыслу текста, из группы брать последний годный, если не сказано иное.
   Спорные — в отдельную секвенцию с пометкой ⚠️, как в Highlights.
3. **Сразу в Premiere**: секвенция «Чистовой черновик» через мост, рядом «Всё вырезанное» — чтобы быстро вернуть кусок.
4. **Чьи слова**: разделение голосов (pyannote или по каналам петличек), чтобы команды оператора не путались с речью героя.
5. **Без LLM на тишине**: сначала карта голоса (Demucs + порог, как в этапе 1+2), в разбор идут только куски с речью.
6. **Окно в Editor**: позже — режим Saturni · Editor с таймлайном, где зелёным то, что остаётся, красным — вырезанное,
   и кнопкой «В Premiere».
